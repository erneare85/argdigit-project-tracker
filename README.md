# Project Tracker — Descargas

Canal público de distribución de Project Tracker para Windows x64.

[Ver instaladores y novedades](https://github.com/erneare85/argdigit-project-tracker/releases)

Este repositorio contiene instaladores, firmas de actualización y notas de versión. El código fuente se mantiene en un repositorio privado. Los proyectos, la configuración y las credenciales de cada usuario permanecen en su equipo y no se distribuyen aquí.

Las nuevas instalaciones se realizan con el instalador de la versión elegida. Las versiones que incorporan actualización automática consultan este canal y verifican la firma del paquete antes de instalarlo, con confirmación del usuario.

Antes de actualizar, guardá los borradores y cerrá Tracker desde la bandeja si usás el instalador manual. Conservá tu espacio de trabajo y configuración.
